# Cut the Rope Recreation

A browser-based recreation of the popular mobile game "Cut the Rope" using HTML5 Canvas and Matter.js physics engine.

## 🎮 Game Overview

Cut the Rope is a physics-based puzzle game where you cut ropes to feed candy to Om Nom, a cute green creature. The goal is to collect all three stars in each level and successfully deliver the candy to Om Nom.

## 🚀 How to Play

1. Open `index.html` in a modern web browser
2. Click and drag your mouse across the ropes to cut them
3. Use physics and timing to collect stars and feed the candy to Om Nom
4. Complete levels to progress through the game

## ✨ Features

- **Physics-based gameplay** using Matter.js engine
- **Multiple levels** with increasing difficulty
- **Star collection system** for bonus scoring
- **Rope cutting mechanics** with mouse/touch support
- **Responsive design** with beautiful gradient UI
- **Touch support** for mobile devices

## 🎯 Game Controls

- **Mouse**: Click and drag across ropes to cut them
- **Touch**: Touch and drag on mobile devices
- **Restart Button**: Restart the current level
- **Next Level Button**: Progress to the next level (unlocked after completing current level)

## 🛠️ Technologies Used

## 🎨 Game Elements

- **Candy**: The pink circular object that needs to reach Om Nom
- **Ropes**: Brown constraints that hold the candy (cut to release)
- **Stars**: Golden collectibles for bonus points
- **Om Nom**: The green character at the bottom who needs to be fed
- **Obstacles**: Platform elements that affect candy movement

## 🏆 Level System

The game includes multiple levels:
- **Level 1**: Simple single rope introduction
- **Level 2**: Two ropes in V-shape configuration
- **Level 3**: Obstacles and platforms
- **Level 4+**: Challenging combinations
