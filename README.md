# Plants vs Zombies

Un juego web inspirado en el clásico Plants vs Zombies, desarrollado con HTML, CSS y JavaScript puro.

## Cómo Jugar

1. Abre `index.html` en tu navegador web
2. Recolecta soles haciendo clic en ellos (caen del cielo y los producen los girasoles)
3. Selecciona una planta del menú superior
4. Haz clic en una celda del tablero para plantar
5. Defiende tu jardín de las oleadas de zombies

## Plantas Disponibles

- **Girasol (50 soles)**: Produce 25 soles cada 24 segundos
- **Lanzaguisantes (100 soles)**: Dispara guisantes que causan 20 de daño
- **Nuez (50 soles)**: Planta defensiva con 400 de salud
- **Guisante Hielo (175 soles)**: Dispara guisantes helados que ralentizan zombies
- **Cereza Bomba (150 soles)**: Explota causando 1800 de daño en área

## Tipos de Zombies

- **Zombie Normal**: 100 de salud
- **Zombie con Cono**: 200 de salud
- **Zombie con Cubo**: 350 de salud

## Características

- Sistema de oleadas progresivas
- 5 tipos de plantas con diferentes habilidades
- 3 tipos de zombies con dificultad creciente
- Sistema de economía basado en soles
- Efectos visuales y animaciones
- Sistema de puntuación
- Detección de victoria/derrota

## Tecnologías Utilizadas

- HTML5
- CSS3 (con animaciones y gradientes)
- JavaScript (ES6+)

## Instrucciones de Desarrollo

Simplemente clona el repositorio y abre `index.html` en tu navegador. No requiere instalación ni dependencias adicionales.
